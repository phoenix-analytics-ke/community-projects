# DAY 1 SET-UP 
The simplest description of git you'll ever need is Git is version control software. GitHub is the point of collaboration to track your changes. If you wan't it could be the place where your most up-to-date personal and team projects live. 

The objective for today is to install git and understand your local working environment. 

## Step1: Install and Configure Git 
Installation Resoures:
[Git Guides](https://github.com/git-guides/install-git)

## Step2: Check Configurations
git --version
git config --global user.name "Your Name"
git config --global user.email "Your Email"
git config --global init.defaultBranch main

### List Configurations:
git config --list
