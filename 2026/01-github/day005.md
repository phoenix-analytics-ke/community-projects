# DAY 5 A BRRIEF INTRODUCTION TO GITHUB
GitHub, popularly recognized by dev and people in the tech space is a remote hosting platform that powers collaboration on tasks|work|projects. Meaning, github simply hosts remote copies of your git commit history. 

Up until this point we have worked in a local environment without interacting with the web interface github. Using various git commands, you can connect your local repository to github and iteratively change on collaborate on projects via push, pull, and pull request commands. 

The objective for day 005 is pretty straight forward. Create a github account (if you don’t have one already) and connect your local repository to a remote one. 

## Step1: Create your challenge repository on github
Create an account if you don’t have one. Log in to GitHub

Click **New repository**

Provide:
   - Repository name (e.g. `git-challenge` or whaever you named your challenge directory)
   - Visibility: Public (recommended for the challenge)

**Do NOT initialize** with:
   - README
   - `.gitignore`
   - License
This ensures your remote repository starts empty and avoids history conflicts.
 
Once created, GitHub will show you a repository URL, we’ll come back to this. 
Let’s go back to your local repository on git bash

## Step2: Check your local repository
Start on a clean working tree: check your status and log your commit history.
`git status`
`git log --oneline`

Add the remote repository you just created on github
`git remote add origin https://github.com/<username>/<repository-name>.git`

i.e `git remote add origin <url of the repository you just created>`

e.g `git remote add origin https://github.com/Ae0nn/git_challenge_test.git`

Verify remote repo exists
`git remote –v`

Now push your local repository to the remote repository
`git push -u origin main`
